# العربية بين يدي طالب العلم — الكتاب التفاعلي

سلسلة لتعليم العربية للناطقين بغيرها (A1–B2)، موجّهة إلى طلاب العلوم الشرعية الأتراك، تُؤلَّف لمجمع السيرة النبوية (سيواس) وكلية عارفان.

- **الكتاب التفاعلي للتدريس:** `kitab.html` — صفحات الكتاب المطبوع نفسها (A4) بتمارين تفاعلية وصوت وترجمة تركية.
- **التثبيت تطبيقاً:** افتح الكتاب على الهاتف ثم اختر «إضافة إلى الشاشة الرئيسية» (أو «تثبيت التطبيق» على الحاسوب)، ويعمل بعد أول فتح دون إنترنت.
